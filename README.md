# Axogram Pro

لوحة تحكم عربية لإدارة حسابات وحملات تيليجرام — **نسخة إنتاجية كاملة**.

> **Full Stack:** React + TypeScript + Vite + Tailwind | FastAPI + SQLAlchemy | PostgreSQL | Redis + RQ | Docker Compose + Nginx

## ما تم إنجازه (حالة 2026-08-01)

### 🚀 محركات تنفيذ حقيقية عبر Telethon (لا بيانات وهمية)
- **إرسال الحملات (DM + قروبات):** محرك إرسال فعلي مع متغيرات `{first_name}` وسبين `{spin:أ|ب}`, إدارة FloodWait (انتظار/تبديل/إيقاف), Slowmode, القائمة السوداء, حدود يومية لكل حساب, تدوير تلقائي, حذف رسائل مؤجل, تقرير نهائي بأسباب الفشل + إعادة للفاشلة + تصدير PDF.
- **إضافة الأعضاء:** `add_participants` حقيقي مع سياسات أخطاء (خصوصية/طرد/جلسة تالفة), تقدم حي, إيقاف/استئناف/إلغاء.
- **التجميع:** مجموعات عامة/خاصة/محادثات + **من المنشورات** (تفاعلات/تعليقات/مشاركات) + دمج وتنظيف الملفات + قوالب محفوظة.
- **استيراد الجلسات:** 5 طرق حقيقية (ملفات .session متعددة / ZIP بكلمة مرور / String Session / ملف نصي) مع فحص اتصال لكل جلسة.
- **التحقق والتسخين:** فحص `get_me` حقيقي لكل حساب + خطة تسخين تنفذ إجراءات فعلية.
- **الجدولة:** مجدول تلقائي يشغّل الحملات (مرة واحدة/يومي/أيام محددة/كل X ساعات) + تسليم الإشعارات + حذف الرسائل المؤجلة + مراقب الحظر الدوري.
- **مجموعات الحسابات (Pools):** CRUD كامل + إسناد الحسابات.
- **إدارة القروبات:** انضمام/مغادرة/تحديث معلومات/تصنيف تلقائي/قائمة سوداء/إحصائيات/استيراد وتصدير — تنفيذ Telethon حقيقي.
- **البروكسيات:** فحص اتصال حقيقي (SOCKS4/5/HTTP CONNECT) + استبدال الميتة بمرشحين.
- **الأمان:** جلسات الأجهزة الحقيقية (GetAuthorizations) وإنهاؤها, تغيير 2FA عبر Telethon (بدون تخزين كلمة المرور), تشفير ملفات الجلسات (AES), طوارئ حقيقية (إيقاف كل المهام/قفل النظام/حذف الجلسات/تنبيه), مراقب حظر دوري, تنظيف حسابات فعلي.
- **الإشعارات:** خدمة إرسال تيليجرام حقيقية (حساب أو بوت) مع سجل أحداث وإعادة إرسال.
- **التقارير:** اليوم/الأسبوع/الشهر أرقام حقيقية من قاعدة البيانات + تصدير PDF/CSV حقيقي.
- **النسخ الاحتياطي:** نسخة JSON كاملة + استعادة + نسخ الجلسات ZIP.
- **نظام المهام الموحد:** كل عملية طويلة = JobRun مع تقدم حي وإيقاف/استئناف/إلغاء (يعمل مع Redis/Worker أو بدونها عبر خيوط خلفية).

### ❌ أُزيلت كل البيانات الوهمية
- `src/data.ts` حُذفت نهائياً — كل الشاشات تقرأ من الـ API.
- أُزيلت كل رسائل النجاح الوهمية (`"تم الحفظ محلياً"`) — الأخطاء تُعرض كما هي من الباك إند.
- أُزيل التوليد الاصطناعي (synthetic) في التجميع والإضافة — إن لم يتوفر حساب بجلسة تُعرض رسالة خطأ واضحة.

## التشغيل المحلي

### الواجهة
```bash
pnpm install && pnpm dev
```

### الباك إند
```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
> يحتاج PostgreSQL وRedis أو استخدم Docker Compose (يعمل أيضاً بدون Redis عبر التنفيذ المباشر).

## التشغيل الكامل عبر Docker Compose

```bash
cp .env.example .env   # غيّر SECRET_KEY وكلمات المرور
docker compose up --build
```

- الواجهة: `http://localhost` — API docs: `http://localhost/api/docs`

## خطوات التفعيل قبل الاستخدام الفعلي

1. من **الإعدادات ← إعدادات API تيليجرام**: ضع `API ID` و `API Hash` (من my.telegram.org).
2. من **مدير الحسابات ← إضافة حساب**: اربط الحسابات عبر OTP (أو استورد جلسات).
3. من **الإعدادات ← الإشعارات**: حدد حساب/بوت استقبال الإشعارات (اختياري).
4. ابدأ: تجميع ← إضافة ← حملات.
